# ORBITAL MVP

A TypeScript + React + Vite prototype for a simplified rocket engineering workstation.

## Commands

- `npm install`
- `npm run dev`
- `npm run test`
- `npm run build`

## Scope

This MVP intentionally uses a simplified simulation model for rapid iteration:

- 2D trajectory view bound to simulation telemetry
- Data-driven rocket component registry
- Stage-based rocket builder
- Basic mission targets (Suborbital / simplified 200 km LEO)
- Simplified gravity, drag, fuel burn, and staging

It is not a high-fidelity aerospace simulation and does not use live external orbital APIs.
